# Production schedule

The app reads `plan/schedule.json`; this file is the readable copy. Edit dates in the JSON, then regenerate or update this table to match.

**Rule:** one video goes live every Friday, starting Fri, Nov 20, 2026. Deadlines per video, counted back from its Friday: script −10 days, voiceover −8, visuals −5, edit −3, title, thumbnail and upload scheduled −2, live on Friday.
